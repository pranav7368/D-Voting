ELECTION COMMISSION

Election administration

Compose the ballot, manage the roll, and open or close the poll. This console has no access to individual votes or the tally.

- -

1. The ballot

The name is prose for a header - nothing verifies against it. The election id below is what every proof and every check is bound to, and it never changes.

One candidate or party per line, in ballot order.

2. The electoral roll

Adding voters is the one power no proof can check, so it is committed instead: freezing the roll produces a digest that is sealed onto the chain. Publish the roll and anyone can confirm the two match.

3. Schedule

Both optional. A closing time is enforced by the clock, not by an operator remembering to act.

4. Open the poll

This seals the candidates, the limits, the schedule, the roll commitment, the trustee roster and the validator set into the chain. None of them can be changed afterwards. Type the election id to confirm.

Polling is open

Closing is irreversible and ends the franchise for anyone who has not yet voted. It is written to the chain, so it stays closed across a restart.

Awaiting the trustees

The count is the one thing this console cannot do. Each trustee holds one share of the election key on their own machine and contributes from their own console. The result appears here when enough have.

The result is on the chain

Sealed with every trustee's decryption proof, so anyone can recount it without asking this server to be believed.
